🛠️ Repository Highlights
The codebase addresses over 110 distinct mathematical challenges from the official course syllabus: 

Numerical Analysis: Full implementations of Bisection, Newton-Raphson, and Runge-Kutta (4th Order) methods for solving non-linear equations and ODEs. 

Linear Algebra: Systematic approaches to matrix inversion via Gauss-Jordan (using elementary row operations), Eigenvalue decomposition, and Cayley-Hamilton Theorem verification. 

Mathematical Modeling: Scripts dedicated to Fibonacci sequences, Stirling’s approximation, and physical systems like the non-linear pendulum. 

Data Visualization: 2D and 3D graphical representations of complex functions, including circular helices and exponential decay models. 

🚀 Technical Workflow
Environment: Developed and tested in the latest MATLAB environment (2025b), utilizing the Symbolic Math Toolbox for exact algebraic results.

Standards: All numerical outputs are calibrated to 5 or 6 decimal places. 

Structure: Modular script files designed for readability and educational clarity.
